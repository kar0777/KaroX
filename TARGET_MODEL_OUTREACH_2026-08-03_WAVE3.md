## Canonical KaroX description used

> KaroX is an open-source, local-first guarded API and MCP bridge that lets AI coding agents work inside a selected Git repository under explicit permissions. It provides retry-safe file and command operations, tests, local Git workflows, browser-based verification, audit evidence, secret filtering, and hard blocks on push, publishing, and destructive actions.

KaroX was not described as a VS Code extension, Minecraft mod, browser game, or generic cloud IDE.

## Outreach rules applied

- Search Gmail Sent before every message, including previous BCC outreach.
- Do not send a new cold message when a previous company contact exists.
- Use only company-published addresses from official sites, documentation, legal pages, repositories, or package metadata.
- Tailor every message to the company’s exact API, model, credit programme, coding product, trial, grant, or infrastructure offer.
- Ask for student/open-source/research evaluation access, API credits, direct plan access, or a formal grant route.
- Do not demand a fixed dollar amount.
- Do not claim that an integration or benchmark has already been completed.
- State that a parent or legal guardian can own or supervise the account and handle KYC, contracts, identity, cards, or payment.
- Do not create accounts, add cards, enable automatic top-up, or accept subscriptions during outreach.
- Do not send passwords, API keys, coupons, private repository content, or other secrets.
- Use Chinese-first bilingual messages for Chinese providers.
- Use only public or synthetic repositories for any future evaluation.
