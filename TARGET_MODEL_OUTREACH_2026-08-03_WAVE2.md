## Canonical KaroX description used

> KaroX is an open-source, local-first guarded API and MCP bridge that lets AI coding agents work inside a selected Git repository under explicit permissions. It provides retry-safe file and command operations, tests, local Git workflows, browser-based verification, audit evidence, secret filtering, and hard blocks on push, publishing, and destructive actions.

KaroX was not described as a VS Code extension, Minecraft mod, browser game, or generic cloud IDE.

## Outreach rules applied

- Search Gmail Sent before every message, including old BCC outreach.
- Do not contact a company again when a prior message exists, unless replying in the existing thread.
- Use only an address published by the company or in its official repository/legal/support material.
- Write every message for the recipient's exact API, model, program, coding product, or infrastructure offer.
- Ask for student/open-source/research evaluation access, API credits, and/or direct plan access.
- Do not request a predetermined dollar amount.
- Do not claim planned benchmarks or integrations have already been completed.
- State that a parent or guardian can handle account ownership, payment, identity, or contractual verification where required.
- Do not create accounts, add cards, enable auto-top-up, or accept paid subscriptions during outreach.
- Do not include secrets, API keys, coupons, passwords, or private repository contents.
- For Chinese providers, send a Chinese-first bilingual message rather than an English-only mass template.

## Status legend

- `SENT_NEW` — first verified outbound message to this exact company/address in the current outreach history.
- `REPLIED` — substantive human response received.
- `APPROVED_ACTION_REQUIRED` — support approved, but activation or verification remains.
- `RECEIVED_ACTIVE` — credits/plan/model access is visible and usable.
- `REFUSED` — the company explicitly declined.
- `STANDARD_ROUTE` — redirected to an ordinary public plan/program without special support.
- `NO_RESPONSE` — no substantive reply after the chosen follow-up window.
- `BOUNCED` — delivery failed.
