# The people and teams helping KaroX grow

### Built by one student — strengthened by an open-source community

KaroX is a student-led open-source project. The organizations and people below provided direct model access, API credits, cloud or GPU resources, browser capacity, research tooling, or other concrete development support.

Their help lets KaroX move beyond mocks and toy examples: real providers, real failure modes, real integrations, and reproducible safety work.

## How this support is used

Support is directed first toward active KaroX implementation and integration work:

- provider adapters, streaming, and protocol compatibility;
- native CLI and hosted-agent integration paths;
- tool calling, structured output, and evidence collection;
- retry safety and duplicate-side-effect prevention;
- permission boundaries, secret filtering, and destructive-action safeguards;
- tests, browser verification, screenshots, and cross-platform reliability;
- controlled public or synthetic evaluations only after the implementation is stable.

## A note from the project

KaroX is deeply grateful to every person who chose to help a young open-source developer keep building. Each grant, account upgrade, technical answer, and encouraging message reduced a real barrier between an idea and a working, testable system.

**Thank you for trusting the project early.**
